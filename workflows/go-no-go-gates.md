# Go/no-go gates

Each gate needs evidence. If a gate fails, pick the smallest honest version of the event that can still happen.

## Gate 1: Commit (before spending money)
- [ ] Artist scorecard routed to Final Review, and the decision-maker said yes
- [ ] Artist role and date agreed in writing
- [ ] Venue path identified with lead time that fits
- [ ] Budget shows a funding path (partners, entry, or capped self-funding)

## Gate 2: Announce
- [ ] Permit or written venue approval in hand (or authority confirmed none needed, in writing)
- [ ] Insurance bound for the date; COI requirements known
- [ ] Registration tested end to end
- [ ] Artist approved announcement copy and visuals
- [ ] Every named partner signed

## Gate 3: Event week
- [ ] COI issued to every required party
- [ ] Medical lead confirmed; EAP complete
- [ ] Weather thresholds and decision owner written
- [ ] Staffed to plan (or capacity reduced to match staffing)
- [ ] Music licensing in place
- [ ] Run of show final; crew briefed

## Gate 4: Morning of
- [ ] Weather check against thresholds at the pre-announced time
- [ ] Site walk: hazards, signage, crossings, restrooms
- [ ] Medical lead and AED on site
- [ ] Crew briefing done

**Fallbacks when a gate fails:** smaller cap, private invite-only version, free walk instead of a produced race, indoor venue, new date. Say which gate failed and why in the message.
