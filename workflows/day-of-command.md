# Day-of command checklist

Event lead keeps this on one sheet.

## Before doors
- [ ] Weather check vs thresholds, decision logged with time
- [ ] Site walk complete
- [ ] Medical lead on site, AED located
- [ ] Every role filled; radios or group text tested
- [ ] Crew briefing done (15 min)
- [ ] Check-in tested on the device being used

## During
- [ ] Count at check-in close, recorded
- [ ] Safety briefing given to participants
- [ ] Sweeps confirmed in every group
- [ ] Artist moments on time; handler confirms exits
- [ ] Partner deliverables photographed
- [ ] Incidents logged as they happen

## After
- [ ] Every participant accounted for (sweeps report in)
- [ ] Site cleaner than we found it
- [ ] Lost and found
- [ ] Incident log filed (even if empty)
- [ ] Check-in export saved
- [ ] Two-line note to the team: what worked, what broke
